## 4. Transaction DB 테이블

> 상세: `@docs/db/db-transaction-spec.md`

| 테이블 | 역할 |
|---|---|
| `outbox_event` | Outbox 이벤트 (published_yn, retry_count, payload) |
| `saga_transaction` | Saga 상태 (STARTED / PROCESSING / SUCCESS / FAILED / COMPENSATING / COMPENSATED) |
| `saga_step_history` | Saga 단계별 이력 (step_name, step_order, step_status, request/response payload) |
| `idempotency_key` | 중복 요청 방지 (PROCESSING / SUCCESS / FAILED) |
| `dead_letter_event` | DLQ 실패 이벤트 (original_topic, retry_count, resolved_yn) |
| `reconciliation_result` | 정합성 검증 결과 (source_count, target_count, mismatch_count) |
| `transaction_audit_log` | 금융 거래 감사 로그 |

**공통 DB 규칙:**
- PK: `bigint generated by default as identity`
- 금액: `numeric(18,2)`, float/double 금지
- 날짜: `timestamp`, ISO-8601
- 감사 컬럼: `trace_id`, `created_at`, `created_by` 필수
- 거래 데이터: INSERT only, UPDATE/DELETE 금지

## 5. 이 서버가 노출하는 API

> 상세: `@docs/api/api-transaction-server.md`

### Bank 계좌 조회 (`/baas/v1/bank/accounts`)

| Method | Path | 설명 |
|---|---|---|
| GET | `/baas/v1/bank/accounts` | 계좌 목록 조회 (`?status=ACTIVE`) |
| GET | `/baas/v1/bank/accounts/{accountId}` | 계좌 상세 조회 |
| GET | `/baas/v1/bank/accounts/{accountId}/transactions` | 거래내역 조회 (fromDate, toDate, page, size) |
| GET | `/baas/v1/bank/accounts/{accountId}/transactions/filter` | 거래 필터 조회 (type, channel, status, minAmount, maxAmount) |
| GET | `/baas/v1/bank/accounts/{accountId}/transactions/categories` | 거래 카테고리 집계 (fromDate, toDate 필수) |

### Bank 이체 (`/baas/v1/bank/transfers`)

| Method | Path | 설명 |
|---|---|---|
| POST | `/baas/v1/bank/transfers` | 이체 실행 (**Idempotency-Key 필수**) |
| POST | `/baas/v1/bank/transfers/{transferId}/approve` | Saga Commit — 출금/입금 반영 |
| GET | `/baas/v1/bank/transfers/{transferId}` | 이체 결과 조회 |

### Stock 조회 (`/baas/v1/stocks`)

| Method | Path | 설명 |
|---|---|---|
| GET | `/baas/v1/stocks/search` | 종목 검색 (`?keyword=`) |
| GET | `/baas/v1/stocks/{stockCode}/price` | 현재가 조회 |
| GET | `/baas/v1/stocks/{stockCode}/charts` | 차트 조회 (interval 필수) |
| GET | `/baas/v1/stocks/accounts/{accountId}/cash-balance` | 예수금 조회 |
| GET | `/baas/v1/stocks/accounts/{accountId}/orders` | 주문 목록 조회 |
| GET | `/baas/v1/stocks/orders/{orderId}` | 주문 상세 조회 |
| GET | `/baas/v1/stocks/accounts/{accountId}/executions` | 체결 조회 |
| GET | `/baas/v1/stocks/accounts/{accountId}/returns` | 수익률 조회 |

### Stock 주문 Write (`/baas/v1/stocks`)

| Method | Path | 설명 |
|---|---|---|
| GET | `/baas/v1/stock/accounts` | 주문 가능 계좌 조회 (**단수 `stock`**) |
| POST | `/baas/v1/stocks/accounts/{accountId}/orders` | 주문 생성 (**Pin-Token + Idempotency-Key 필수**) |
| POST | `/baas/v1/stocks/orders/{orderId}/cancel` | 주문 취소 (**Pin-Token + Idempotency-Key 필수**) |

### Stock 보유 종목 (Internal)

| Method | Path | 설명 |
|---|---|---|
| GET | `/internal/v1/stock/accounts/{accountId}/holdings` | 보유 종목 조회 |

### 포트폴리오

| Method | Path | 설명 |
|---|---|---|
| GET | `/baas/v1/total/portfolio` | 포트폴리오 조회 (`?accountId=` 필수) |

> **주의:** 주문 가능 계좌 조회는 `/baas/v1/stock/accounts` (단수), 나머지 Stock API는 `/baas/v1/stocks/...` (복수)

## 6. 공통 응답 포맷

```java
// 성공
{ "success": true, "data": {}, "meta": { "traceId": "uuid" } }

// 실패
{ "success": false, "error": { "code": "TRANSFER_002", "message": "..." }, "meta": { "traceId": "uuid" } }

// 페이지네이션 data 구조
{ "content": [], "page": 0, "size": 20, "totalElements": 0, "totalPages": 0 }
```

**공통 헤더:**
- `Authorization: Bearer {accessToken}` — 인증 필요 API
- `Pin-Token: {pinToken}` — 금융 Write API (주문 생성/취소)
- `Idempotency-Key: {uuid}` — 이체/주문 API
- `X-Trace-Id: {uuid}` — 내부 서버 간 통신

## 8. Saga 상태 흐름

```
STARTED → PROCESSING → SUCCESS
                    → FAILED → COMPENSATING → COMPENSATED
```

**step_status:** `SUCCESS` / `FAILED` / `COMPENSATED`

## 9. Kafka 설정 (인프라 포트)

| 항목 | 값 |
|---|---|
| Kafka | 9092 |
| Kafka UI | 8085 |

- Consumer 멱등성 보장 필수
- Outbox 이벤트: `published_yn=false` 폴링 후 발행, 실패 시 `retry_count` 증가
- DLQ 실패 시 `dead_letter_event` 테이블에 저장
